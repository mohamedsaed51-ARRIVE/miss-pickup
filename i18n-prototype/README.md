# نموذج أولي: التبديل بين العربية والإنجليزية (miss-pickup)

نسخة **معزولة** من اللوحة (`index.html` الأصلية في جذر المشروع لم تُعدَّل). تجرّب `arrive-i18n.js` — نواة الترجمة المشتركة المقترحة لباقي اللوحات.

- `arrive-i18n.js` — النواة: حفظ اللغة (`?lang=` ← localStorage ← الافتراضي)، RTL/LTR، الجمع عبر `Intl.PluralRules`، كشف المفاتيح الناقصة (`ArriveI18n.missing()`، وضع `?i18nDebug=1`)، ترجمة قيم الشيت للعرض فقط (`tv`) مع قائمة `unmapped()`، استقبال اللغة من البوابة عبر `postMessage` من أصول مصرّح بها فقط.
- `miss-pickup.dict.js` — القاموس (180 مفتاحًا × لغتين) + ترجمة القيم المضبوطة.
- `index.html` — اللوحة والتقرير A4 بعد استخراج كل النصوص.
- `tests/i18n.test.js` — 40 اختبارًا (`node i18n-prototype/tests/i18n.test.js`).

مبدأ: قيم الشيت العربية تبقى هي المفتاح المنطقي لكل الحسابات والفلاتر؛ الترجمة للعرض فقط.
التشغيل المحلي: افتح `i18n-prototype/index.html` (الأصول تُقرأ من `../assets` و`../miss_pickup_cases.json`).
